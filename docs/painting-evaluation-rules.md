# 描画評価ルール

この文書は、完成画像だけでなく途中経過も含めて描画を評価するための基準です。

## 評価観点

| 観点 | 内容 |
| --- | --- |
| 構図 | 頭部位置、肩の傾き、全体比率が参照と合っているか |
| シルエット | 顔・ターバン・衣服の大きな外形が早い段階で読めるか |
| 明暗 | 光側・影側が大きな塊として整理されているか |
| 顔構造 | 目・鼻・口・顎の位置関係が成立しているか |
| エッジ | 硬い・柔らかい・消える境界を使い分けているか |
| ストローク方向 | 部位の立体、布、重力に沿った方向になっているか |
| 道具適合 | 工程と部位に対して適切な道具を使っているか |
| 混色 | Mixer / Smudge が局所的な絵具操作として使われているか |
| 描き込み配分 | 顔・目・口・真珠など重要部へ描画量が集中しているか |
| 背景配分 | 背景に描画時間を使いすぎていないか |
| 動画自然さ | 画像が出現するのではなく、筆で組み立てているように見えるか |

## 工程別の合格目安

| 工程 | 合格目安 |
| --- | --- |
| 構図 | 少数の線だけで位置・傾き・比率が理解できる |
| 大きな形 | 細部がなくても人物、ターバン、衣服が読める |
| 明暗の面 | 顔の立体と主要色面が感じられる |
| 顔構造 | 細密描写なしでも顔の向きと特徴が成立している |
| 細部 | 全域ではなく重要部の解像度が上がる |
| 仕上げ | 少数の調整でハイライト、色味、エッジが締まる |

## 代表的な失敗

- 左上→右下など同一角度のストロークが画面全体を支配する。
- 序盤から短線・点を大量に配置し、最終的な画素一致で似せる。
- 大きな形の段階では似ておらず、細部工程で無理に修復する。
- Smudge を使いすぎて目鼻口や輪郭が溶ける。
- Glaze を使いすぎて全体が濁る。
- 背景の変化に動画時間を使う一方で、主体の形が進まない。
- 顔と衣服を同じ密度で描き込み、重要度の差がない。

## 自動評価で確認する項目

- 6工程が正しい順序で連続している。
- 禁止ブラシや画像参照が含まれない。
- Mixer / Smudge / Glaze の工程ルールを守る。
- 大きな形・明暗工程の広い筆について、角度ヒストグラムが1方向へ過度に集中しない。
- 顔・ターバン・衣服で異なる方向分布が存在する。
- 完成画像のMAE / PSNRが最低品質閾値を満たす。

自動指標は人間の目視評価を置き換えません。特にストローク方向、工程の自然さ、描き込み配分は動画とチェックポイントを目視で確認します。
