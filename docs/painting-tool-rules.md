# 描画道具の使い分けルール

この文書は `llm-painting-lab` における描画道具の役割・使用タイミング・禁止事項を整理したものです。
目的は、道具を増やすだけでなく、**工程ごとに何を使い、何を使わないか** を明確にして、描画品質と描画過程の自然さを両立することです。

## 1. 前提

本リポジトリの優先目標は次の2つです。

1. 最終完成画像の品質を上げること
2. 途中経過が「人が描いているように見える」こと

そのため、単純な画素一致だけを最適化せず、工程ごとに適切な道具を使い分けます。

## 2. 標準6工程

1. 構図
2. 大きな形
3. 明暗の面
4. 顔構造
5. 細部
6. 仕上げ

## 3. 道具一覧

| 道具 | 主な役割 | 主な使用工程 |
| --- | --- | --- |
| ラフ線ブラシ | あたり、中心線、位置決め | 構図、顔構造 |
| 平筆（大） | 大きな塊、ブロックイン | 大きな形、明暗の面 |
| 平筆（中） | 中規模の面、色面整理 | 明暗の面、顔構造 |
| 細筆 | 目・口・鼻・輪郭・真珠 | 顔構造、細部、仕上げ |
| dryBrush | かすれた太い筆跡、下塗り感 | 大きな形、明暗の面 |
| Mixer Brush | 下地色と新しい色の混色 | 明暗の面、顔構造、仕上げ |
| Smudge Brush | 既存色をなじませる、引きずる | 明暗の面、仕上げ |
| Glaze | 低透明度の色膜を重ねる | 仕上げ |
| Variable-width Brush | 入り・抜き、筆圧、線の表情 | 構図、顔構造、細部 |
| 消し筆 / 拭き取り | 描きすぎた場所を戻す | 顔構造、細部、仕上げ |
| Mask / Alpha Lock | 塗る範囲の制御 | 大きな形、明暗の面、顔構造 |

## 4. 工程ごとの使い分け

### 4.1 構図

**目的**: 顔中心線、目線、口位置、肩の流れ、輪郭、真珠位置の目安を取る。

**使う**: ラフ線ブラシ、Variable-width Brush。

**使わない**: Smudge、Glaze、強い Mixer Brush。

**ルール**:
- 線は少数に抑える。
- 位置決めが目的で、完成感は求めない。
- 太さは入り・抜きを付け、機械的な一定幅線にしない。

### 4.2 大きな形

**目的**: 顔、ターバン、衣服、背景との境界を大きな塊として立ち上げる。

**使う**: 平筆（大）、dryBrush、Mask / Alpha Lock。

**使わない**: 細筆、細かい Smudge、Glaze。

**ルール**:
- 円形スタンプや四角い色パッチは使わない。
- 太い筆を往復させて塊を作る。
- 同じ部位では筆方向をある程度揃える。
- 背景は地塗りとしてほぼ固定する。

### 4.3 明暗の面

**目的**: 顔の光面 / 影面、ターバン、黄色布、衣服の明暗を面として整理する。

**使う**: 平筆（大・中）、dryBrush、Mixer Brush、弱い Smudge Brush。

**使わない**: 細筆中心の描き込み、強い消し込み。

**ルール**:
- 先に面を作ってから混ぜる。
- Mixer は境界で下地色を拾いながら使う。
- Smudge は形を壊さない範囲だけに限定する。
- 全面を均一にぼかさない。

### 4.4 顔構造

**目的**: 目、鼻筋、口、顎、頬の立体を構造として成立させる。

**使う**: 平筆（中）、Variable-width Brush、細筆、軽い Mixer Brush、必要に応じて消し筆、Mask / Alpha Lock。

**使わない**: 強い Smudge、広域 Glaze。

**ルール**:
- いきなり細部へ行かず、構造を先に取る。
- 顔は他部位より優先度を高くする。
- Smudge の使いすぎで目鼻口を溶かさない。

### 4.5 細部

**目的**: 目、唇、鼻先、ターバン縁、真珠、輪郭を決める。

**使う**: 細筆、Variable-width Brush、必要に応じてごく弱い Mixer Brush、消し筆。

**使わない**: 広い平筆、広域 Smudge、広域 Glaze。

**ルール**:
- この工程は「混ぜる」より「決める」。
- 目・真珠・口など視線が集まる部位を優先する。
- 背景や低重要度部位は描き込みすぎない。

### 4.6 仕上げ

**目的**: ハイライト、輪郭整理、色味調整、視線誘導、描きすぎの抑制。

**使う**: 細筆、Glaze、弱い Smudge Brush、局所 Mixer Brush、消し筆。

**使わない**: 大きなブロックイン用の太筆。

**ルール**:
- Glaze は薄く使い、全体を濁らせない。
- Smudge は必要なソフトエッジだけに使う。
- 真珠、目、鼻先など少数のアクセントで絵全体を締める。

## 5. 道具選択の4条件

道具は次の4条件で選択する。

1. 現在の工程
2. 対象（顔 / ターバン / 衣服 / 背景 / 真珠）
3. 目的（位置決め / 塊作成 / 面整理 / 構造決定 / 細部決定 / 調整）
4. 必要なエッジ特性（硬い / 柔らかい）

例:

- `明暗の面 × 顔 × 光と影を自然につなぐ` → 平筆（中） + Mixer Brush + 弱い Smudge Brush
- `細部 × 真珠 × ハイライトを決める` → 細筆 / Variable-width Brush
- `仕上げ × 顔 × 赤みを薄く足す` → Glaze

## 6. 禁止ルール

標準実験では以下を避ける。

- 円形スタンプを格子状に大量配置する。
- 四角い色パッチで序盤を構成する。
- 背景の細かな変化に動画時間を大きく割く。
- 全工程を同じ粒度の短線だけで描く。
- 構造未確定のまま Smudge で溶かす。
- どの工程でも同じ筆を機械的に使い続ける。
- Mixer / Smudge / Glaze を「画質を良くする魔法のフィルタ」として全域適用する。

## 7. 実装優先度

1. Mixer Brush
2. Smudge Brush
3. Glaze
4. Variable-width Brush
5. 消し筆 / 拭き取り
6. Mask / Alpha Lock の標準化
7. 観察補助（左右反転、グレースケール、比率確認）

## 8. 実装方針

- 道具は単に追加せず、**工程ごとの使用ルールとセット**で導入する。
- 動画では「何の目的でその道具を使っているか」が途中経過から分かることを重視する。
- 完成画像の忠実度だけでなく、途中経過が画家の作業として自然かも確認する。
- Mixer / Smudge はキャンバス上の既存色を参照し、単純な Gaussian Blur とは区別する。
- Glaze は低透明度の色膜として扱い、形状生成には使わない。
