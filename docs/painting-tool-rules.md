# 描画道具・部位・工程の使い分けルール

この文書は `llm-painting-lab` の標準描画ルールを定義します。目的は、完成画像の類似度だけでなく、途中経過も「人が絵を組み立てている」ように見せることです。

道具は単独で選びません。**工程 × 部位 × 目的 × エッジ特性**の4条件で選択します。

## 1. 標準工程

| 工程 | 目的 |
| --- | --- |
| 1. 構図 | 全体位置、傾き、比率、主要位置を決める |
| 2. 大きな形 | 顔・ターバン・衣服・背景の大きな塊を作る |
| 3. 明暗の面 | 光と影、主要な色面を整理する |
| 4. 顔構造 | 目・鼻・口・顎・頬の構造を成立させる |
| 5. 細部 | 視線が集まる部分だけを描き込む |
| 6. 仕上げ | ハイライト、色味、エッジ、視線誘導を調整する |

## 2. 道具一覧

| 道具 | 主な役割 | 主な使用工程 |
| --- | --- | --- |
| ラフ線 / `variableBrush` | あたり、中心線、入り抜きのある輪郭 | 構図、顔構造、細部 |
| `flatBrush` | 大きな面、ブロックイン、広い塗り | 大きな形、明暗の面 |
| `dryBrush` | 下塗り、かすれ、粗い面 | 大きな形、明暗の面 |
| `mixerBrush` | 下地色を拾いながら新しい色と混ぜる | 明暗の面、顔構造、仕上げ |
| `smudgeBrush` | 既存色を筆方向へ引きずってなじませる | 明暗の面、仕上げ |
| `glaze` | 薄い色膜を重ねて色味を調整する | 仕上げ |
| `line` | 目・口・鼻・輪郭・真珠などの決め | 顔構造、細部、仕上げ |
| erase / wipe | 描きすぎた場所を戻す、エッジを整える | 顔構造、細部、仕上げ |
| `clipBox` / Mask | 描画範囲を制御する | 大きな形、明暗の面、顔構造 |

## 3. 部位ごとの基本方針

| 部位 | 重要度 | 基本方針 |
| --- | ---: | --- |
| 顔 | 最重要 | 構造・明暗・エッジ・細部を最優先する |
| 真珠 | 高 | 小さいが視線が集まるため終盤で少数の強い筆で決める |
| ターバン | 高 | 大きな色面と布の巻き・折れ方向を明確にする |
| 衣服 | 中 | 大きな形と明暗を優先し、細部は抑える |
| 背景 | 低〜中 | 地塗り中心。主役を邪魔せず、動画時間を使いすぎない |

## 4. 部位ごとのストローク方向

方向はランダムでも固定でもなく、**その部位の形状に追従する方向場**から決めます。

| 部位 | 主方向 | 補助方向 | 避けること |
| --- | --- | --- | --- |
| 顔 | 頬・額・顎の立体に沿う曲面的な方向 | 目は横、鼻筋は縦、口は横の特徴方向 | 全面を同じ斜め棒線で埋める |
| ターバン | 頭部を回り込む巻き方向、布の折れ方向 | 局所的なしわ・エッジ方向 | 面と無関係な均一角度 |
| 衣服 | 重力方向、肩から落ちる方向 | 折れ目・輪郭に沿う方向 | 全域で同一の斜め方向 |
| 真珠 | 形を壊さない短い弧・輪郭補助 | ハイライト方向 | 細かな多線・点でざらつかせる |
| 背景 | 広く均す方向、ゆるい横流れ | 局所的な変化 | 全面同一角度、後半の細密描画 |

### 方向場の優先順位

1. 部位の立体・布・重力などの**形状方向**
2. 参照画像の局所エッジ・明暗境界の方向
3. 小さな揺らぎ

序盤ほど 1 を強くし、細部ほど 2 の影響を増やします。3 は単調さを消すためだけに使い、ランダム方向そのものを目的にしません。

## 5. 工程 × 部位 × 道具

### 構図

| 部位 | 使う道具 | やること | 使わない道具 |
| --- | --- | --- | --- |
| 顔 | `variableBrush` | 顔中心線、目線、鼻・口位置、傾き | Mixer、Smudge、Glaze |
| ターバン | `variableBrush` | 外形、ボリューム、傾き | Mixer |
| 衣服 | `variableBrush` | 肩、首元、大きな流れ | `flatBrush` |
| 真珠 | ラフ線 | 位置だけ取る | 細部描写 |
| 背景 | 原則なし | 地塗りを前提にする | 細密描画 |

### 大きな形

| 部位 | 使う道具 | やること | 使わない道具 |
| --- | --- | --- | --- |
| 顔 | `flatBrush`、`dryBrush`、Mask | 暖色下塗りから顔の塊を作る | 細線中心の描写 |
| ターバン | `flatBrush`、`dryBrush` | 青・黄の大きな色面を布方向に塗る | 細筆中心 |
| 衣服 | `flatBrush`、`dryBrush` | 暗い塊を落ち方向に作る | 細線大量配置 |
| 真珠 | 原則まだ描かない | 位置維持 | ハイライト決め |
| 背景 | 地塗り | ここでほぼ固定 | 後半の細かな更新 |

### 明暗の面

| 部位 | 使う道具 | やること | 注意 |
| --- | --- | --- | --- |
| 顔 | `flatBrush`、`mixerBrush`、弱い `smudgeBrush` | 光面と影面を面として整理 | 先に面を作り、後から必要箇所だけ混ぜる |
| ターバン | `flatBrush`、`mixerBrush` | 布方向に沿って濃淡を作る | 全面を均一にぼかさない |
| 衣服 | `flatBrush`、`dryBrush` | 暗部と中間調を整理 | 細部へ進みすぎない |
| 背景 | 原則触らない | 主役との分離だけ確認 | 動画時間を使わない |

### 顔構造

| 部位 | 使う道具 | やること | 注意 |
| --- | --- | --- | --- |
| 顔 | `variableBrush`、`line`、軽い Mixer、必要に応じて wipe | 目・鼻・口・顎・頬の関係を成立させる | 強い Smudge で構造を溶かさない |
| ターバン | `variableBrush` | 額との境界、布の縁 | Glaze はまだ使わない |
| 真珠 | `line` | 輪郭の目安 | 完成ハイライトは後回し |

### 細部

| 部位 | 使う道具 | やること | 注意 |
| --- | --- | --- | --- |
| 顔 | `variableBrush`、`line` | 目、唇、鼻先、必要な輪郭 | 重要部に集中する |
| ターバン | `variableBrush`、`line` | 縁、折れ目のアクセント | 全域を細密化しない |
| 衣服 | 少数の `variableBrush` / `line` | 必要なアクセントのみ | 細部量を抑える |
| 真珠 | 細筆 | 輪郭、反射、ハイライト準備 | 点や短線の大量配置を避ける |
| 背景 | 原則なし | 主役を邪魔しない | 細部追加禁止 |

### 仕上げ

| 部位 | 使う道具 | やること | 注意 |
| --- | --- | --- | --- |
| 顔 | `glaze`、弱い Smudge / Mixer、細筆、wipe | 色味、ハイライト、エッジ | 全体を濁らせない |
| ターバン | `glaze`、細筆 | 色味と重要な縁 | 大きな塗り直しを避ける |
| 衣服 | 少量の `glaze` | まとまり調整 | 細部を増やしすぎない |
| 真珠 | 細筆、必要なら薄い `glaze` | 少数のハイライトで決める | 過剰描写を避ける |
| 背景 | 必要なら最小限 | コントラスト調整 | 大きく変更しない |

## 6. 類似させるための判断ルール

道具だけでなく、次の順序で判断します。

1. **構造・比率**: 頭部、顔幅、目線、鼻・口、肩の位置関係
2. **大きな明暗**: 光側・影側を数個の大きな塊として読む
3. **エッジ**: 硬い / 柔らかい / 消える境界を選ぶ
4. **色の相対関係**: RGBの一点一致より、周囲に対して暖かい・暗い・彩度が低い等を優先
5. **ストローク方向**: 部位の形状に追従する
6. **重要度**: 顔・目・口・真珠へ描画量を集中する
7. **見直し**: 工程ごとに構造・明暗・エッジを再評価する
8. **減算修正**: 上書きだけでなく、wipe・薄め・面の作り直しを使う

後半の細線・細点で画像全体を復元することを主戦略にしません。**大きな形と明暗の段階で既に似ている状態**を目標にします。

## 7. 禁止ルール

| 禁止事項 | 理由 |
| --- | --- |
| 円形スタンプを格子状に大量配置する | 人の描き方に見えない |
| 四角い色パッチを序盤に貼る | 付箋のように見える |
| 全部を同じ斜め方向の棒線で塗る | 部位の形状に追従していない |
| 全工程を同じ粒度の短線で描く | 画像再構成・プリンタ的に見える |
| 構造未確定で強く Smudge する | 顔や輪郭が溶ける |
| Mixer / Smudge / Glaze を全域フィルタとして使う | 絵具操作ではなく後処理になる |
| 重要でない領域まで均等に描き込む | 視線誘導と作業配分が不自然になる |
| 背景更新に大きな動画時間を使う | 主体の制作過程が伝わらない |

## 8. 実装方針

- 道具追加と使用ルールを必ずセットで変更する。
- 序盤は部位別方向場を強く使い、細部ほど局所エッジ方向を混ぜる。
- Mixer / Smudge はその時点のキャンバス色を参照し、Gaussian Blurとは区別する。
- Glaze は低透明度の色膜として仕上げに限定する。
- 完成画だけでなく、各チェックポイントと動画を評価する。
- 自動検査では「広い工程のストローク角度が1方向に集中していないこと」も検証する。
