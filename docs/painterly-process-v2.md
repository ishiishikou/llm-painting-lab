# 画家に近い描画工程 v2

ユーザー確認で判明した以下の問題を修正する実験です。

- シルエット工程が円形スタンプの格子状描画に見える
- 背景の細かな更新が動画上で分かりにくい
- ストローク数比例の動画再生により、構図やシルエット工程が一瞬で終わる

## v2 の方針

1. 構図は少数のガイドと輪郭メモだけにする
2. 大きな形は円形スタンプではなく長く太い筆致で置く
3. 明暗の面も人物領域へ長い筆致を重ねる
4. 背景は地塗りとして最初から置き、進捗ストロークに含めない
5. 顔構造を独立工程として再度描き起こす
6. 細部・仕上げは人物領域へ集中する
7. 動画は総ストローク数比例ではなく工程ごとに時間配分する

動画の標準時間配分は以下です。

| 工程 | 割合 |
| --- | ---: |
| 構図 | 10% |
| 大きな形 | 16% |
| 明暗の面 | 25% |
| 顔構造 | 15% |
| 細部 | 23% |
| 仕上げ | 11% |

これにより、少数ストロークの構図工程も目視でき、背景の見えにくい更新に時間を使わず、人物が絵として立ち上がる過程を追えるようにします。
