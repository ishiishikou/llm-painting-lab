# v8: 視覚レビュー駆動の描画プロトコル

v8では、描画中の次の行動をPythonが参照画像の画素差から自動決定しません。

## 原則

1. 生成器 `tools/generate_vision_guided_v8.py` は参照画像を入力として受け取らない。
2. 参照画像はレビュー時にだけ使用する。
3. レビュアーは「参照画」と「現在のpreview」を実際に見比べ、次の**一仕事**を `vision/v8-plan.json` に追記する。
4. 一仕事は「頬の明るい面を作る」「青いターバンの大きな塊を置く」のように、目的を一つに限定する。
5. 描画後は再レンダリングして再び視覚確認する。悪化した操作は無効化できる。
6. 道具は固定周期で使わない。見た目上の必要性があると判断した時だけ選ぶ。
7. 構図線・下描き・Smudge・Glazeなどを「人が使うから」という理由だけでは追加しない。

## Python側がしてよいこと

- JSONで明示されたストローク群を決定論的に展開する。
- 指定されたellipse / polygonなどの幾何形状内に筆を分布させる。
- 指定された色、筆、方向、太さ、透明度を実行する。
- 現在のstrokesをCanvasへレンダリングする。

## Python側がしてはいけないこと

- 参照画像を `Image.open` する。
- 参照画像のRGB、明暗、勾配、エッジを取得する。
- 現在画との画素誤差から次の部位や筆を選ぶ。
- 残差ランキングを作る。
- 「7本ごとにMixer」のような固定周期で道具を選ぶ。

## レビュー粒度

固定本数にはしません。

- 大きな形: 20〜100筆程度の意味のある一仕事
- モデリング: 5〜20筆程度
- 目・鼻・口・真珠: 1〜5筆程度
- 最終アクセント: 1〜3筆程度

重要なのは筆数ではなく、**一度のレビュー間に目的を一つだけ持つこと**です。

## 評価

CIで参照画像とのMAEなどを計算してもよいですが、その数値を生成器へ戻して次の筆を自動選択しません。数値は回帰確認用であり、次の制作判断は視覚レビューで行います。
